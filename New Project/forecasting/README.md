# ต้นแบบพยากรณ์ยอดขายรายวัน

หน้าจอ Forecast Studio ใช้เมนู 4 ส่วน: ภาพรวมและทำนาย, แนะนำจำนวนซื้อ,
นำเข้าข้อมูล, ผลประเมินโมเดล กราฟและการ์ดภาพรวมคำนวณจากข้อมูลสินค้าที่เลือก
กราฟแสดงยอดขายจริงย้อนหลัง 28 วันก่อนวันเป้าหมาย รองรับหน้าจอขนาดเล็ก
ธีมใน `theme.css` ถูกฝังใน HTML เมื่อสร้าง จึงไม่ต้องคัดลอกไฟล์ CSS ไปเครื่องสาธิต

## คำแนะนำซื้อและค่าความคลาดเคลื่อน

หลังทำนายวันถัดจากข้อมูลล่าสุด กรอกของเหลือที่ยังขายได้และหน่วยต่อแพ็ก
จำนวนแพ็ก = ceil(max(0, คำทำนาย - ของเหลือ) / หน่วยต่อแพ็ก)
จำนวนหน่วยซื้อ = จำนวนแพ็ก × หน่วยต่อแพ็ก
รองรับจำนวนเต็มไม่ติดลบสำหรับสต็อก และจำนวนเต็มบวกสำหรับขนาดแพ็ก
คำแนะนำไม่มีสต็อกเผื่อ สมมุติรับของทันวันเป้าหมาย ผู้ใช้ต้องหักของหมดอายุเอง
ไม่ใช่โมเดล AI ที่เรียนรู้จำนวนซื้อ และยังไม่มีหลักฐานว่าลดของเสียหรือของขาด
เปลี่ยนสินค้า วันที่ สต็อก หรือขนาดแพ็ก จะล้างคำแนะนำเก่า
เลือกวันทดสอบย้อนหลังยังดูคำทำนายได้ แต่ไม่สามารถขอคำแนะนำซื้อด้วยสต็อกปัจจุบัน
ดาวน์โหลด CSV คำแนะนำซื้อได้

งานถดถอยรายงาน MAE/RMSE ไม่ใช่ accuracy แบบจำแนก
หน้าเว็บเพิ่ม WAPE = sum(abs(prediction-actual))/sum(actual) × 100
ค่า M5 ทดสอบ 140 คำทำนายคือประมาณ 29.90% ใช้คำทำนายจริงก่อนปัดขึ้นซื้อ
ไม่เรียก 100-WAPE ว่า accuracy สำหรับชุดข้อมูลนำเข้ารายงานแยกสินค้า
หากยอดขายจริงรวมเป็นศูนย์จะแสดงว่าคำนวณ WAPE ไม่ได้

ใช้ข้อมูล M5 ร้าน `CA_1` และสินค้าอาหาร 5 รหัสที่เลือกจากข้อมูลช่วงฝึก
ข้อมูลเป็นจำนวนขาย ไม่ใช่สต็อก และไม่ได้ระบุชื่อหรืออายุสินค้าจริง

## ใช้งาน

ติดตั้ง Python พร้อม `numpy` และ `pandas` แล้วรัน:

```text
python "New Project/forecasting/train_forecast.py"
```

ข้อมูลต้นทางต้องอยู่ใน `New Project/Dataset/m5-forecasting-accuracy/selected_5_foods.csv`
มีหัวตาราง `วันที่,รหัสสินค้า,จำนวนที่ขาย` ตามไฟล์ที่จัดเตรียมไว้
ไฟล์ผลทดลองอยู่ในโฟลเดอร์ `ai_results` ภายในโฟลเดอร์ข้อมูล:

- `forecast_report.html`: รายงานภาษาไทย เปิดด้วยเบราว์เซอร์ เลือกสินค้าและดูผลรายวันได้
- `predictions.csv`: คำทำนายและยอดขายจริง
- `metrics.csv`: MAE, RMSE และความเอนเอียงของแต่ละวิธี
- `experiment.json`: ช่วงข้อมูล วิธีทดลอง รุ่นเครื่องมือ และรหัสตรวจสอบข้อมูลต้นทาง
- `model_*.npz`: ค่าน้ำหนักโมเดลและข้อมูลการปรับมาตราส่วน

## นำเข้าข้อมูลและฝึกใหม่

หน้าเว็บรับ CSV UTF-8 (มีหรือไม่มี BOM) หัวตารางภาษาไทย
`วันที่,รหัสสินค้า,จำนวนที่ขาย` หรือภาษาอังกฤษ `date,item_id,sales`
เรียงคอลัมน์ใหม่ได้ รองรับช่องที่ใส่เครื่องหมายคำพูดตามรูปแบบ CSV
วันที่ต้องเป็น YYYY-MM-DD แต่ละสินค้ามีอย่างน้อย 90 วันต่อเนื่อง
จำนวนขายเป็นจำนวนเต็มไม่ติดลบ วันที่ซ้ำหรือขาดจะถูกปฏิเสธ ไม่เติม 0 อัตโนมัติ
รองรับสูงสุด 5 MB, 20,000 แถว และ 20 สินค้า

เลือกไฟล์แล้วกด “นำเข้าและฝึก AI” เพื่อฝึกโมเดลใหม่ของแต่ละสินค้า
ใช้ Ridge Regression, alpha=1, ไม่ penalize intercept, ปรับมาตราส่วน
ด้วยค่าเฉลี่ยและ population standard deviation จากช่วงฝึกเท่านั้น
ตัวแปรเหมือนโมเดล M5; กำหนดค่าปรับไว้ก่อนทดสอบ ไม่เลือกจากผลทดสอบ
Ridge ช่วยเมื่อข้อมูลนำเข้าสั้นหรือมีตัวแปรสัมพันธ์กันสูง
ดังนั้นโมเดลนำเข้าต่างจาก OLS ที่ใช้กับข้อมูล M5 ที่ติดมากับหน้าเว็บ
ผลจากไฟล์ตัวอย่าง 180 วันไม่ควรเทียบโดยตรงกับรายงาน M5 ที่ฝึกหลายปี

กัน 28 วันสุดท้ายไว้ทดสอบ โมเดลทดสอบฝึกถึงวันก่อนช่วงทดสอบและคงที่
แต่ละคำทำนายใช้ยอดขายจริงที่ทราบถึงวันก่อนหน้า (one-step rolling)
รายงาน MAE ของ AI และค่าเฉลี่ย 28 วันพร้อมส่งออก CSV ผลทดสอบทุกสินค้า
สำหรับทำนายวันถัดจากข้อมูลล่าสุด จะใช้โมเดลอีกชุดที่ฝึกด้วยข้อมูลทั้งหมด
เมื่อเลือกวันทดสอบย้อนหลัง ใช้โมเดลทดสอบเดิม จึงไม่ใช้โมเดลสุดท้ายย้อนทำนาย
ผลทดสอบเป็นหลักฐานของขั้นตอนทดลอง ไม่ใช่คะแนนของโมเดลสุดท้ายโดยตรง

ไฟล์ `sample_sales_import.csv` เป็นข้อมูลจริงจาก M5 5 สินค้า 180 วัน
ใช้สาธิตการนำเข้า ไม่ใช่ข้อมูลร้านของผู้ใช้ ข้อมูลนำเข้าอยู่ในหน่วยความจำ
ไม่ส่งไปเซิร์ฟเวอร์ ไม่เก็บถาวร เมื่อรีโหลดต้องเลือกไฟล์และฝึกใหม่
หากไฟล์ผิด ชุดข้อมูลและโมเดลที่ใช้อยู่เดิมยังใช้ได้

ตรวจด้วย `python "New Project/forecasting/check_import.py"` (ต้องมี Node)
หรือระบุ `--node` ตามด้วย path ของ Node โปรแกรมจะตรวจ parser,
วันที่ขาด/ซ้ำ, ค่าขายผิด, ข้อมูลคงที่ และการไม่ใช้คำตอบอนาคตฝึกโมเดลทดสอบ
แล้วเทียบค่าน้ำหนัก คำทำนาย และ MAE ใน JavaScript กับ NumPy อีกชุด
ไฟล์ตรวจสอบที่สร้างอยู่ในโฟลเดอร์ผลทดลองที่ถูกยกเว้นจาก GitHub

## รายละเอียดวิธีทดลอง

สร้างชุดสาธิตด้วย `python "New Project/forecasting/package_demo.py"`
ไฟล์ ZIP และโฟลเดอร์พร้อมใช้จะอยู่ใน `Dataset/m5-forecasting-accuracy/delivery`
แตก ZIP ทั้งชุดแล้วเปิด `START_HERE.html` เพื่ออ่านวิธีใช้งานและสาธิต
ชุดสาธิตไม่ต้องติดตั้ง Python หรือเปิดเซิร์ฟเวอร์ ใช้เบราว์เซอร์ที่รองรับ JavaScript
ตัวจัดชุดตรวจเทียบไฟล์ต้นฉบับ ตรวจ ZIP CRC และ SHA256 ทุกไฟล์
ข้อมูลและชุดสาธิตถูกยกเว้นจาก GitHub เช่นเดียวกับ Dataset

Linear Regression ใช้ NumPy least squares เพื่อเรียนรู้ค่าน้ำหนักจากข้อมูล
ปรับมาตราส่วนจากข้อมูลฝึกเท่านั้น และจำกัดคำทำนายให้ไม่ติดลบ
เปรียบเทียบกับยอดขายวันเดียวกันสัปดาห์ก่อน ค่าเฉลี่ย 7 วัน และค่าเฉลี่ย 28 วัน

ฝึกถึง 28 กุมภาพันธ์ 2016 ตรวจผล 29 กุมภาพันธ์–24 เมษายน 2016
จากนั้นฝึกใหม่ถึง 24 เมษายน และทดสอบ 25 เมษายน–22 พฤษภาคม 2016
ไม่มีการเลือกตัวแปรหรือปรับโมเดลตามคะแนนช่วงทดสอบ
ตัวแปรยอดขายใช้ข้อมูลก่อนวันเป้าหมายเสมอ รวมถึงค่าเฉลี่ยที่เลื่อนข้อมูลก่อนคำนวณ
แต่ละวันใช้ยอดขายจริงถึงวันก่อนหน้า จึงเป็นการทำนายล่วงหน้าหนึ่งวันซ้ำ 28 ครั้ง
ไม่ใช่การทำนาย 28 วันล่วงหน้าในครั้งเดียว

ตัวตรวจสอบในโปรแกรมยืนยันวันที่ต่อเนื่อง คู่วันที่–สินค้าไม่ซ้ำ และข้อมูลเป็นตัวเลขถูกต้อง
ตรวจค่า lag และค่าเฉลี่ยกับข้อมูลย้อนหลังโดยตรง และเปลี่ยนยอดขายอนาคตเพื่อยืนยันว่า
ตัวแปรของวันก่อนหน้าและวันเป้าหมายไม่ได้เปลี่ยนตามคำตอบอนาคต

MAE ต่ำกว่าหมายถึงคลาดเคลื่อนเฉลี่ยน้อยกว่า ต้องรายงานกรณี AI แพ้วิธีพื้นฐานตามจริง
สินค้าเหล่านี้ถูกเลือกให้มีข้อมูลขายต่อเนื่อง ผลจึงยังไม่แทนสินค้าทั้งหมด
ยังไม่มีคำแนะนำสั่งซื้อ การประเมินของเสีย หรือผลยืนยันกับร้านในประเทศไทย
